# 🤖 Telegram Shop Bot (@LVoptBot)

Лаконичный Telegram-бот для заказов и каталога товаров с учётом остатков на складе и встроенной админ-панелью.

---

## 🚀 Основные возможности

1. **🛍 Каталог товаров:**
   - Категории товаров.
   - Текстовые карточки: название, описание, цена, статус наличия.
   - **Учёт остатков:** при каждой заявке количество автоматически списывается. Если товар закончился (0 шт.), он помечается как `❌ Нет в наличии`, и его нельзя добавить в корзину.

2. **🛒 Корзина и заказ:**
   - Добавление товаров, изменение количества (`+` / `-`), удаление позиций, очистка корзины.
   - Оформление заказа: запрос номера телефона (по кнопке контакта или текстом) и комментария.
   - **Уведомление владельцу:** при оформлении бот сразу присылает детальную заявку с контактами покупателя в личные сообщения владельцу.

3. **⚙️ Админ-панель (внутри бота):**
   - Добавление и удаление категорий.
   - Добавление товаров (категория, название, описание, цена, остаток).
   - Управление складом: изменение остатка, обновление цены, удаление товара.

## ⚡ Быстрый старт локально

1. Установите зависимости:
   ```bash
   npm install
   ```

2. Соберите проект:
   ```bash
   npm run build
   ```

3. Запустите бота:
   ```bash
   npm start
   ```
   *(для разработки: `npm run dev`)*

---

## 👑 Как назначить себя владельцем (Администратором)

Есть два простых способа:

- **Способ 1 (самый быстрый):**
  Напишите боту команду `/claim_admin` в Telegram. Если владелец ещё не назначен, бот моментально сделает вас администратором.
- **Способ 2 (через файл `.env`):**
  Напишите боту команду `/id`, скопируйте свой цифровой Telegram ID и пропишите его в файл `.env`:
  ```env
  ADMIN_ID=ваш_id
  ```

## 🌐 Бесплатный хостинг и деплой

### 1. Как залить проект на GitHub:
```bash
git init
git add .
git commit -m "Initial commit of TG Shop Bot"
git branch -M main
git remote add origin https://github.com/ВАШ_АККАУНТ/ВАШ_РЕПОЗИТОРИЙ.git
git push -u origin main
```
*(Файл `.env` с токеном уже добавлен в `.gitignore` и не попадет в публичный доступ).*

---

### 2. Бесплатный деплой на Render.com (Бесплатный тариф):
1. Зарегистрируйтесь на [Render.com](https://render.com) через GitHub.
2. Нажмите **New +** -> **Web Service**.
3. Подключите ваш GitHub-репозиторий.
4. Выберите среду: **Docker** (Render сам обнаружит `Dockerfile`).
5. В разделе **Environment Variables** добавьте:
   - `BOT_TOKEN` = `ваш_токен_бота`
   - `ADMIN_ID` = `ваш_telegram_id`
6. Нажмите **Deploy Web Service**. Бот запустится и будет работать 24/7!

---

### 3. Деплой на Railway.app (Бесплатный триал $5/мес):
1. Зайдите на [railway.app](https://railway.app) через GitHub.
2. Нажмите **New Project** -> **Deploy from GitHub repo**.
3. Добавьте переменные окружения `BOT_TOKEN` и `ADMIN_ID` во вкладке **Variables**.
4. Railway автоматически соберет Dockerfile и запустит бота.

---

### 4. Запуск на VPS (Ubuntu / Debian):
```bash
# Через Docker Compose:
docker compose up -d --build

# Или через PM2:
npm install -g pm2
npm run build
pm2 start dist/bot.js --name "tg-shop-bot"
pm2 save
pm2 startup
```
